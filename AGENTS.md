# GSOM contributor and agent instructions

## Required language

Use English only for all project-authored repository content and official communication.
This includes source code, identifiers, comments, documentation, examples, configuration
text, file and directory names, commit messages, issues, pull request titles and
descriptions, review comments, release notes, and other published project messages.

Before committing or publishing, review the changed content and communication for
language compliance. Translate non-English additions into English before submission.
This policy applies to this standalone addon repository even when it is checked out
as a submodule inside a parent project that uses another language.
